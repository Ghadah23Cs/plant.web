# 🌿 Plant Web - Categories & Varieties

## 📝 About The Project
**Plant Web** is a web application designed to showcase various plant species, their classifications, benefits, and care details. This page highlights **Aromatic Plants** like *Lavender* and *Patchouli*, detailing their botanical families, origins, habitats, and visual guides.

## ✨ Features
* **Detailed Plant Catalog:** Presents essential information (Family, Origin, Habitat) in structured, readable tables.
* **Visual Gallery:** High-quality images showcasing each plant variety.
* **Simple Navigation:** Fast access across different sections (Home, Varieties, Video, Benefits, Team, Contact).
* **Custom Styling:** Styled with CSS gradients and responsive design elements.

## 📁 Project Structure
* `Home.html` - Homepage overview.
* `cate.html` - Plant varieties and categories catalog.
* `Video.html` - Educational videos about plants.
* `benefits.html` - Health and ecological benefits of plants.
* `Team.html` - Project team members.
* `Contact.html` - Contact form and details.
* `css/styile.css` - Custom styling sheet.
* `images/` - Visual assets and background imagery.
